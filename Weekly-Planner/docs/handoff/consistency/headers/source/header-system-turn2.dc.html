Weekly Planner · header system · turn 1

One header, four variants

Each header uses the same slot order: ◀ back (only on screens without the bottom nav) · title (no emoji) · context (a date or a ◀ period ▶ stepper) · up to 2 actions · profile badge, always at the far right. A second row is optional and has one style everywhere. All four variants use paper, a 2.5px navy rule underneath, stay pinned while scrolling, and use 44px+ buttons. Shown at iPad 1194 and phone 390, in 1a Pop and 1b Calm.
